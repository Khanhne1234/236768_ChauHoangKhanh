# Hệ thống quản lý món ăn

Ứng dụng quản lý món ăn gồm frontend React, backend Node.js/Express
và cơ sở dữ liệu MongoDB Atlas.

## Công nghệ
- React, Vite
- Node.js, Express
- MongoDB Atlas, Mongoose
- Docker, Docker Hub
- Render

## Cấu trúc
- `client/`: giao diện frontend
- `server/`: backend API

## Cách chạy
Hướng dẫn chạy frontend và backend sẽ được cập nhật khi hoàn thành các phần tiếp theo.

## Triển khai
- Frontend: cập nhật sau
- Backend API: cập nhật sau
- Docker Hub: cập nhật sau
