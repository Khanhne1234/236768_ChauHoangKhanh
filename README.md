# Hệ thống quản lý món ăn

Ứng dụng quản lý món ăn gồm frontend React, backend Node.js/Express
và cơ sở dữ liệu MongoDB Atlas.

## Công nghệ
- React, Vite
- Node.js, Express
- MongoDB Atlas, Mongoose
- Docker, Docker Hub
- Render

## Cấu trúc
- `client/`: giao diện frontend
- `server/`: backend API

## Cài đặt

Mở Terminal tại thư mục dự án và cài các thư viện:

```bash
cd server
npm install
cd ../client
npm install
